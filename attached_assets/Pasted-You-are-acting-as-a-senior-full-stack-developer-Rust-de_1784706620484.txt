ACCESS MODES
==================================================

Support two access modes.

MODE 1 — EMPLOYEE AUTHORISED ACCESS

This is the default method.

Workflow:

1. IT administrator clicks Remote Access.
2. Administrator enters:
   - Support reason
   - Ticket number
   - Expected session duration
   - View Only or Remote Control
3. Employee receives a visible request on the laptop.
4. Employee sees:
   - Administrator name
   - Department
   - Support reason
   - Ticket number
   - Requested access mode
5. Employee can:
   - Allow Remote Control
   - Allow View Only
   - Decline
6. The request expires automatically after 120 seconds.
7. After approval, the remote session starts.
8. Employee sees a persistent active-session banner.
9. Either the administrator or employee can end the session.

MODE 2 — SUPER ADMIN DIRECT ACCESS

Super Admin may start direct access only when all conditions below are met:

- The laptop is company-owned.
- The asset is actively managed.
- The Miles Agent is installed and online.
- A company remote-support policy permits unattended support.
- The Super Admin has the required permission.
- The Super Admin enters a mandatory reason.
- A valid ticket or incident number is entered when required.
- The action is fully logged.
- The employee laptop displays a visible active-session notification.
- The session has a maximum time limit.
- The session can be terminated from the laptop.
- The direct-access policy is enabled by an authorised system owner.

Super Admin direct access must not be hidden.

When direct access begins, show on the employee laptop:

“Miles IT Support has started an authorised remote-support session on this company-managed device.”

Display:

- Administrator name
- Reason
- Ticket number
- Session start time
- End Session button

Do not provide silent or invisible access.
